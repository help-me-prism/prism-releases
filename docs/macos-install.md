# macOS 설치 안내

1. 저장소 첫 화면 또는 릴리즈의 **macOS Apple Silicon 설치·실행 패키지 ZIP**을 다운로드합니다. 현재 배포 파일은 M 시리즈 Mac용입니다.
2. ZIP을 풀고 함께 들어 있는 **Prism_설치_및_실행_가이드_macOS.pdf**를 먼저 읽습니다.
3. 실행 중인 Prism을 종료한 뒤 DMG를 열어 Prism을 Applications(응용 프로그램) 폴더에 복사합니다. 이전 버전이 있으면 교체합니다.
4. 응용 프로그램 폴더의 Prism을 실행합니다. 첫 실행이 차단되면 동봉한 가이드에 따라 **시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기**로 해당 앱을 허용합니다.

현재 Mac 배포는 임시(ad-hoc) 서명이며 Apple 공증은 제공하지 않습니다. 최초 허용 절차가 필요할 수 있습니다. 기존 논문·노트·설정 폴더는 삭제하지 마세요.
