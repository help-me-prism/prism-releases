# 선택형 사용 통계 안내

적용 대상: 사용 통계 기능이 포함된 Prism beta.7 이후 버전. 기존 beta.6에는 이 기능이 없습니다.

사용 통계는 기본 꺼짐이며 첫 안내 또는 **설정 → 사용 통계**에서 전송에 동의한 경우에만 수집·전송합니다. 참여하지 않아도 모든 기능을 이용할 수 있습니다. 설정에서 언제든 끌 수 있습니다.

## 보내는 정보

- 이 앱의 설치를 구분하기 위해 임의로 만든 ID
- 통계 참여 후 최초 실행일, 앱을 실행한 날짜 (한국 시간)
- 읽기 창에서 PDF를 성공적으로 연 횟수와 설치별 중복을 뺀 논문 수

논문 제목·본문·DOI·파일 경로·대화 내용·계정·기기 고유번호는 보내지 않습니다. 논문 중복 여부는 기기 안에서만 확인하고 숫자만 전송합니다. 같은 논문을 여러 설치에서 열면 각각 집계하므로 전 세계 고유 논문 수나 출판 성과 수를 뜻하지 않습니다.

## 보관과 접근

통계는 Prism 개발팀의 Cloudflare 서버에 보관합니다. 개발팀만 관리자 인증 후 조회할 수 있으며 공개 GitHub 저장소나 공개 대시보드에 통계를 게시하지 않습니다. 앱에 관리자 인증 키가 포함되지 않습니다.

앱 서버는 원본 IP를 저장하지 않습니다. 네트워크 전송 과정에서 Cloudflare는 IP를 처리하며, 서버는 일별로 달라지는 해시값을 요청 제한에 사용합니다.

일별 설치 기록은 최대 400일 보관한 뒤 설치와 연결되지 않는 날짜별 합계로 바꿉니다. 설치별 누적 수와 날짜별 합계는 서비스 운영 기간 동안 보관합니다. Cloudflare 백업에는 플랫폼 보존 정책이 적용됩니다. 전송에 실패한 일별 기록은 기기에 최근 30일분을 보관하고 다시 연결되면 재시도합니다.

참여를 끄면 새 집계와 전송을 중단합니다. 이미 전송된 통계는 자동으로 삭제되지 않습니다. 다시 참여하면 같은 설치 ID로 이전 참여 기간의 누적 수를 이어갑니다.

GitHub가 제공하는 공개 배포 파일의 다운로드 수는 GitHub API에서 외부에도 보입니다. 위 비공개 사용 통계와는 별개입니다.
