# Windows 설치 안내

1. [Prism Windows x64 설치 파일](https://github.com/help-me-prism/prism-releases/releases/download/v0.2.0-beta.6/Prism-0.2.0-beta.6-Windows-x64.exe)을 다운로드해 실행합니다.

2. **Windows의 PC 보호** 화면이 나타나면 공식 Prism 릴리스에서 받은 파일인지 확인한 뒤 **추가 정보**를 누릅니다.

![Windows의 PC 보호 화면에서 추가 정보 선택](images/windows-smartscreen-more-info.png)

3. 앱 이름이 `Prism`으로 시작하는지 확인하고 **실행**을 누릅니다.

![Windows의 PC 보호 화면에서 실행 선택](images/windows-smartscreen-run-anyway.png)

4. 설치 화면의 안내에 따라 설치합니다. 기본 설치 위치는 `%LOCALAPPDATA%\Programs\Prism`이며 바탕화면 바로가기를 선택할 수 있습니다. 설치가 끝나면 다운로드한 EXE는 삭제해도 됩니다.

스크린샷의 파일명은 촬영 당시 버전입니다. 실제 파일명은 내려받은 Prism 버전에 따라 달라질 수 있습니다.

현재 Windows 설치 파일의 SHA-256은 `392a2dfb54a215f0380add93ab86874e4dabaecc434a82cfd964628b8f5d528a`입니다. SHA-256은 파일이 배포 후 바뀌지 않았는지 확인하기 위한 공개 정보입니다.
